# Design and Analysis of Algorithms (DAA)

Welcome to my DAA repository! This space documents my progress as an Information Technology B.Tech student mastering core data structures and algorithmic problem-solving. 

## 🚀 About This Repository
This repository contains my personal implementations, time complexity analyses, and comparisons of various algorithms. It serves as both a tracker for my daily coding practice and a library of optimized solutions.

## 💻 Tech Stack
* **Language:** C++
* **Topics Covered:**
  * ✅ Searching Algorithms (Linear vs. Binary Search)
  * ✅ Sorting Algorithms (Bubble, Insertion, Merge Sort)
  * ⏳ Divide and Conquer
  * ⏳ Dynamic Programming
  * ⏳ Greedy Algorithms

## 📁 Repository Structure
* `Searching algorithm.cpp` - Implementation and performance comparison of search techniques.
* `Sorting_Algorithms.cpp` - Implementation and time execution comparison of O(n^2) and O(n log n) sorting techniques.
